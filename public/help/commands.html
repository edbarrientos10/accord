WORKSPACE HANDBOOK / AGENTS

Command reference

Generated from shared command metadata and validators. Do not edit this file directly.

All mutations require a reason and an idempotency key. Field-level authorization, assignment, lifecycle, and semantic refinements still apply. “Human, agent” means an explicitly scoped agent, not any caller. People mutations also require people.read. Read the agent guide before invoking a command and use OpenAPI for exact required fields, types, defaults, and limits.

person.import

Import one reviewed profile and optional birthday atomically. Existing profile/birthday updates require reviewed versions. Empty imported fields never erase values; no automatic duplicate merge.

  • Callers: human, agent.
  • Required mutation scope for non-human callers: person.import. Also requires people.read.
  • Version target: person and optional birthday for updates; none for new records.
  • REST: POST /api/v1/commands/person.import.
  • MCP: accord_person_import.

person.create

Create a contact and third-party identity atomically. Name and reason required; group defaults to Other. No account or message is created.

  • Callers: human, agent.
  • Required mutation scope for non-human callers: person.create. Also requires people.read.
  • Version target: none.
  • REST: POST /api/v1/commands/person.create.
  • MCP: accord_person_create.

person.update

Edit or archive a contact profile. Profile changes do not count as meaningful contact; unresolved commitments remain visible.

  • Callers: human, agent.
  • Required mutation scope for non-human callers: person.update. Also requires people.read.
  • Version target: person.
  • REST: POST /api/v1/commands/person.update.
  • MCP: accord_person_update.

workstream.create

Create a task with optional links (id, title, HTTP/HTTPS url, optional note). Human or explicitly scoped workspace agent; defaults to verified completion. The UI explicitly selects simple completion.

workstream.update

Update task planning, progress, next action, or links. Links replaces the full list: preserve existing entries when adding; omit to keep, [] to clear. Authorized agents can add, edit, and remove links. Workspace agents with workstream.manage may change owner, assignments, or project. Only the human can change outcome, mode, policy, criteria, or clear external conflicts. Preserve existing references.

  • Callers: human, agent.
  • Required mutation scope for non-human callers: workstream.update.
  • Version target: task.
  • REST: POST /api/v1/commands/workstream.update.
  • MCP: accord_workstream_update.
